# ART_DIRECTION_3_0 — Premium Cute 2D Campus RPG 아트 규칙

> 목표: 아기자기한 2D 캐주얼 RPG 감성(따뜻한 색, 부드러운 빛, 풍부한 소품)을 **독자적인 디자인 언어**로 구현합니다.
> 특정 게임(메이플스토리 등)의 캐릭터, 의상, 맵, 아이템, UI, 음악은 복제하지 않습니다. 참고하는 것은 '분위기'뿐입니다.

## 0. 제작 방식과 에셋 출처
- 이 개발 환경에는 이미지 생성 도구가 없습니다. 그래서 모든 배경과 캐릭터는 **코드로 작성한 SVG 벡터 일러스트**입니다(그라데이션·필터·레이어 사용).
- 외부 이미지, 폰트 이외의 외부 에셋, 스톡 이미지는 **쓰지 않습니다**. 폰트는 기존 Pretendard(OFL)만 씁니다.
- 실제 한국외대 건물이나 사진을 따라 그리지 않습니다. 서울캠퍼스(도심, 붉은 벽돌, 은행나무)와 글로벌캠퍼스(호수, 정자, 숲)의 **공개적으로 알려진 분위기**만 참고합니다. 명수당은 "호수 위 정자가 있는 풍경"이라는 요소만 참고하고, 형태는 일반적인 한국 전통 정자 양식으로 새로 그립니다.

## 2. 선과 형태
- **외곽선**: 순수 검정 금지. 대상 색을 어둡게 한 색(예: 잎 → `#3f7a45`, 피부 → `#c98d6e`)을 씁니다. 두께는 배경 오브젝트 1.5~2px, 캐릭터 1.6~2.2px입니다. 먼 배경은 외곽선을 생략합니다.
- 모서리는 둥글게(rx 4~16) 처리하고, 가는 장식선은 50% 투명도로 씁니다.
- 직사각형만 반복하지 않습니다. 지붕 곡선, 창틀 아치, 잎 덩어리, 덤불의 불규칙 곡선을 씁니다.

## 3. 빛과 그림자
- 광원은 **왼쪽 위**로 통일합니다(모든 장면 공통).
- 오브젝트마다 ① 기본 그라데이션(위 밝게) ② 오른쪽 아래 그림자면(검정 8~15% 투명도) ③ 바닥 접지 그림자(타원, `rgba(40,30,20,0.18)`, 블러 2~4)를 넣습니다.
- 실내는 창·조명에서 나오는 빛줄기(흰색·노랑, 10~25% 투명도, 사다리꼴)를 넣습니다.
- 장면 전체에 비네트(가장자리 6~10% 어둡게)를 깔고, 상단에 은은한 빛 번짐을 둡니다.

## 4. 원근과 레이어
- 시점: 약간 위에서 내려다보는 정면 2.5D(오블리크)입니다. 바닥은 화면 아래로 갈수록 가깝습니다.
- 레이어 순서:
  1. 하늘
  2. 원경(산·도시 실루엣, 채도 낮게, 대기원근 흐림)
  3. 중경(건물·나무)
  4. 바닥
  5. 근경 소품
  6. 캐릭터(y 정렬)
  7. 전경 장식(꽃·잎, 일부만)
- 캐릭터 키는 문 높이의 약 60%입니다. 걷기 영역 위쪽에서 0.82배, 아래쪽에서 1.08배입니다.
- 넓은 장면(1600)은 카메라가 학생을 따라갑니다. 원경 레이어는 패럴랙스(0.3~0.6배)로 천천히 움직입니다.

## 5. 캐릭터 (SD)
- 2.2~2.4등신입니다. 머리 폭이 어깨의 약 1.6배이고 손발은 작은 둥근 형태입니다.
- **고유 요소**(특정 게임 캐릭터와 다르게): 큰 둥근 머리 + 볼 홍조 + 얼굴 아래쪽에 모인 이목구비 + 두 갈래 하이라이트가 있는 눈 + 짧은 몸통에 의상 레이어
- 레이어(뒤→앞):
  1. 그림자
  2. 뒷머리
  3. 다리·하의
  4. 신발
  5. 몸통·상의(또는 세트)
  6. 팔
  7. 목·머리
  8. 얼굴(눈·입·홍조)
  9. 앞머리
  10. 모자
  11. 안경
  12. 액세서리
- 의상은 슬롯별 독립 레이어라 상의와 하의를 따로 바꿀 수 있습니다. 세트 의상이 있으면 상의·하의를 숨깁니다.
- 애니메이션: idle(호흡 2px), walking(다리 교차 + 몸 흔들림), greeting(손 흔들기), thinking(고개 기울임 + 말풍선), speaking(입 모양 교대), encouraging(깡충 + 반짝임). 움직임 줄이기 설정이면 정지합니다.

## 6. 환경 애니메이션 (절제)
흔들리는 나뭇잎(±1.5°), 구름 이동, 분수 물결, 호수 반짝임, 김 오르는 커피 정도만 씁니다. 동시에 3~4종을 넘기지 않고, 반짝임은 작고 느리게(2~4초 주기) 둡니다.

## 7. UI
- 창은 크림색 `#fffaf2`, 테두리 `#ead9bf`, 둥근 모서리 16~20px, 그림자는 부드럽게, 제목 띠는 teal→navy 그라데이션입니다.
- 버튼은 둥근 알약형이고, 주요 버튼만 teal로 칠합니다. 아이콘은 lucide입니다.
- 글자: Pretendard. 본문 14~15px, 대화 15px, 줄간격 1.6입니다. 대비는 WCAG AA(4.5:1) 이상이며 배경 위 글자에는 반투명 판을 깝니다.
- 실제 정보와 가상 정보 배지 색: 가상 = amber, 검증된 실제 선배 = emerald, AI = teal, 시연 계정 = slate.

## 8. 금지
- 굵은 검정 외곽선(3px 이상) 금지
- 단색 평면만으로 넓은 면 채우기 금지(그라데이션이나 패턴 필요)
- 장면마다 다른 광원·외곽선 규칙 금지
- 특정 IP 로고·캐릭터·아이템 형태 금지
