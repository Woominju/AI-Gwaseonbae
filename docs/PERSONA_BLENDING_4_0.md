# PERSONA_BLENDING_4_0 — 스타일 혼합

## 1. 의미
비중은 **설명 방식의 상대적 비율**이다. 추천 정확도나 성공 확률이 아니며, 화면에도 그렇게 표시한다.

## 2. 설정
기본 스타일, 보조 스타일, 기본 스타일 비중(50·60·70·80%). 단독이면 100%. 미리보기는 고정된 예시 문장이며 LLM을 호출하지 않는다.

## 3. 비중이 생성에 반영되는 방식
총 8문장 예산으로 환산한다.

| 기본 비중 | 기본 : 보조 문장 |
|---|---|
| 50 | 4 : 4 |
| 60 | 5 : 3 |
| 70 | 6 : 2 |
| 80 | 7 : 1 |

| 모드 | 방식 |
|---|---|
| CPU Demo | 같은 사실 묶음에서 스타일별 문장을 예산만큼 골라, 기본 스타일로 시작·마무리하고 보조 문장을 사이에 배치 |
| 실제 LLM | 두 스타일의 정의, 문장 예산, 문장별 배치 계획을 **한 번의 호출**에 담아 하나의 글을 생성 |

두 답변을 만들어 이어 붙이지 않는다.

## 4. 호출 효율
| 상황 | LLM 호출 |
|---|---|
| 새 질문 | 2회 (사실 답변 + 스타일 답변, 병렬) |
| 같은 질문의 스타일 변경 | 1회 (사실 답변 캐시 재사용) |
| 3.0 | 2회 (사실 답변 + 3관점 JSON) |

5개 스타일을 미리 생성하지 않는다. 호출 수는 fetch 목 단위 테스트로 검증했다.

## 5. 측정 결과 (Qwen3-14B, 물리 GPU 2번)
| 항목 | 결과 |
|---|---|
| 스타일 변경만, 단독 | 중앙값 8.8~10.7초 |
| 스타일 변경만, 혼합 | 중앙값 10.1~15.1초 |
| 스타일 호출 토큰 (중앙값) | 입력 2,973 / 출력 259 |
| 외부 유료 API | 사용 안 함 (자체 GPU) |

문장 계획 적용 후(3차) 표지 표현 (조건당 8턴):

| 조건 | 측정 | 전략 표지 | 공감 표지 |
|---|---|---|---|
| 전략 50 + 공감 50 | 3차 | 3.5 | 2.75 |
| 전략 60 + 공감 40 | 3차 | 2.5 | 2.88 |
| 전략 80 + 공감 20 | 3차 | 3.5 | 2.75 |

## 6. 검증된 것과 아닌 것
- **검증됨:** 비중이 프롬프트에 실제로 들어간다(단위 테스트). 혼합 시 두 스타일의 표지가 함께 나타난다. 문장 계획 도입 후 보조 스타일이 끝 문단에 몰리지 않고 분산됐다.
- **검증되지 않음:** 실제 LLM에서 **비중의 크기 차이가 출력에 반영되는지.** 50%와 80%의 표지가 같았다. 모델이 문장 수 지시를 정확히 따르지 않고(지시 8문장보다 길어짐), 조건당 표본도 8개로 작다.
- CPU Demo에서는 비중이 문장 수로 정확히 반영된다(단위 테스트).

화면의 비중 표시는 설명 방식의 설정값이다. 실제 LLM 출력의 정밀한 혼합 비율을 보장한다고 안내하면 안 된다. 개선 후보는 문장 단위 생성과 사후 검증, 또는 소규모 파인튜닝(별도 승인 필요)이다.
