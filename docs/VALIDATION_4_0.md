# VALIDATION_4_0 — 검증 결과

> 2026-11-09 · 격리 포트 3410~3413 · 실제 LLM은 물리 GPU 2번만 사용

## 1. 무한 로딩 조사
정상 조건(14개 경로, 데스크톱·CPU 6배 저하·폰)에서는 재현되지 않았다. 장애 조건에서 재현했고 수정했다.

| 재현 조건 | 3.0 증상 | 4.0 수정 | 재검증 |
|---|---|---|---|
| 상담 API 무응답 | 스피너가 끝나지 않고 입력 잠김 | 130초 타임아웃, 경과 시간, "그만 기다리기" | E2E |
| 실행 중인 서버 아래서 `next build` | 정적 파일 400, JS 미실행, "확인 중" 고정, 입력 잠김 | `safe_build.sh`가 빌드 거부, 파일 로드 실패 안내 | E2E |
| `/api/status` 429 JSON | 앱 화면 전체 중단 (TypeError) | 응답 형식 검증 | E2E |
| `/api/status` 실패·무응답 | "확인 중" 고정 | 10초 제한, 실패 표시 | E2E |
| 프록시 524 HTML | JSON 파서 오류 원문 노출 | 안내 문구 | E2E |

재현 방법: Playwright로 해당 경로를 차단·지연시키거나, 서버 실행 중 빌드를 교체한다. 이 현상들이 3.0 때 보고된 증상과 같은 사건인지는 확인할 수 없다. 실행 중인 5개 서버의 정적 파일 불일치는 0건이었다.

## 5. 해결하지 못한 문제
- 자동 지표는 대리 지표다. 답변 품질은 개발 중 표본을 읽어 확인했을 뿐, 학생·전문가 평가가 없다.
- 실제 LLM의 비중 세분화가 검증되지 않았다.
- 스타일 답변은 사실 답변과 병렬로 생성되므로 강조점이 다를 수 있다.
- 캐시가 끝나면(10분) LLM 사실 답변의 문장이 달라질 수 있다.
- "학점은 중요한 요소 중 하나" 같은 일반 진술은 가드를 통과한다.
- CPU 템플릿의 스타일 답변은 항상 존댓말이다.
- 임베딩·리랭커 경로의 Q&A 검색은 시험하지 않았다.
- 저사양 대응은 움직임 비활성화까지이며 장면 사전 렌더링은 없다.
