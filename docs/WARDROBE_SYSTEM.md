# WARDROBE_SYSTEM — 아바타 데이터 구조·의상 레이어·저장 방식

## 1. 데이터 구조 (`web/src/lib/world/wardrobe.ts`)
```ts
interface AvatarLook3 {
  faceShape: "round" | "soft" | "oval";           eyes: "dot" | "sparkle" | "gentle" | "sleepy";
  expression: "smile" | "grin" | "calm" | "wink";  skin: string;            // SKIN_TONES 중 하나
  hair: string; hairColor: string;                 // hair = 아이템 ID, HAIR_COLORS
  top: string; topColor: string; bottom: string; bottomColor: string;      // CLOTH_COLORS
  set: string | null;                              // 세트 의상(있으면 상·하의 대신 표시)
  shoes: string; hat: string | null; glasses: string | null; accessory: string | null;
}
```
- 슬롯 9개: 헤어, 얼굴, 상의, 하의, 원피스·세트, 신발, 모자, 안경, 액세서리
- 아이템 34종:
  - 헤어 7(머리색 8)
  - 상의 5(색 13)
  - 하의 4(색 13)
  - 세트 4: 정장, 연구실 가운, 겨울 패딩, 여름 원피스
  - 신발 4
  - 모자 4
  - 안경 3
  - 액세서리 5: 목도리, 백팩, 헤드폰, 크로스백, 에코백
- 얼굴 옵션: 얼굴형 3, 눈 4, 표정 4, 피부색 6
- 결제·게임 재화·확률형 아이템은 없습니다. 모든 아이템은 처음부터 사용할 수 있습니다.

## 2. 렌더링 (`web/src/components/world/Avatar3.tsx`)
- 약 2.3등신 SD 캐릭터입니다. 발끝이 (0,0)이고 키는 약 150 단위입니다(장면에서 원근에 따라 0.82~1.08배).
- 레이어(뒤→앞):
  1. 그림자·하이라이트 링
  2. 백팩 본체
  3. 뒷머리
  4. 다리(피부·양말·하의·신발)
  5. 골반·치마
  6. 목
  7. 상의 또는 세트
  8. 가방끈
  9. 팔
  10. 목도리
  11. 머리(귀·얼굴·홍조·눈·눈썹·입·앞머리·헤드폰 밴드·모자·헤드폰·안경)
  12. 에코백
  - 손을 드는 동작(인사·응원)에서는 팔을 머리 위에 그립니다.
- 각 슬롯이 독립 레이어라 상의와 하의를 따로 바꿀 수 있습니다. 세트를 고르면 상·하의를 숨기고, 상·하의를 고르면 세트가 해제됩니다(옷장 UI).
- 색을 바꿀 수 있는 의상은 선택한 색에서 그림자색과 외곽선색을 자동으로 계산합니다(`shadeOf`, `inkOf`). 순수 검정 외곽선은 쓰지 않습니다.
- 상태: idle, walking, greeting, thinking, speaking, encouraging. 애니메이션 클래스 `w3a-*`는 `prefers-reduced-motion`이나 `.w3-reduce` 상태에서 정지합니다.
- `facing=-1`은 좌우 반전입니다. 이름표는 반전하지 않습니다.
- 그라데이션 ID는 인스턴스마다 고유합니다(`useId`). 한 화면에 여러 캐릭터가 있어도 충돌하지 않습니다.

## 3. 저장 방식
| 키 (localStorage) | 내용 |
|---|---|
| `hufs-atlas:wardrobe:v1` | 학생 아바타(AvatarLook3) |
| `hufs-atlas:wardrobe:outfits:v1` | 보관한 착장 최대 3벌 |
| `hufs-atlas:world:senior-looks:v1` | AI 선배 3명의 외형 (학생과 별도) |
| `hufs-atlas:lounge:seniors:v1` | AI 선배 성격·인사 방식 (2.0과 공유) |

- 불러올 때 `sanitizeLook3`가 **허용 목록으로만** 정규화합니다. 모르는 ID, 다른 슬롯의 ID, 허용되지 않은 색은 기본값으로 바꿉니다. 이것으로 저장값 변조와 스크립트 주입을 막습니다.
- 서버로 보내지 않습니다. 외형은 상담 엔진 입력에 들어가지 않으므로 상담 내용과 근거에 영향을 주지 않습니다.
- "전체 초기화"(`resetAll`)는 기존 라운지 키를 지웁니다. 옷장 키는 사용자가 옷장의 "기본 의상으로" 버튼으로 되돌립니다.

## 4. 화면 흐름 (`/wardrobe`)
1. 처음 접속하거나 저장값이 없으면 **캐릭터 만들기**가 나옵니다(`?step=create`): 얼굴형, 눈, 표정, 피부색, 헤어와 색, 기본 상·하의, 신발, 액세서리 → "이 캐릭터로 시작하기"(저장)
2. **옷장**
   - 왼쪽: 카테고리 9개
   - 가운데: 미리보기(서 있기·걷기·인사·응원 포즈, 방향 바꾸기), 보관한 착장
   - 오른쪽: 아이템 그리드. 각 칸이 그 아이템을 입힌 실제 미리보기이고, 상·하의·헤어는 색상 견본이 있습니다
   - 아래: 저장, 착장 보관, 기본 의상으로, 광장으로 돌아가기(저장하지 않은 변경이 있으면 확인)
3. 저장하면 캠퍼스(선배 광장·서울·글로벌)의 이동 캐릭터에 바로 반영됩니다. 새로고침해도 유지됩니다.

## 5. 한계
- 신발·모자·액세서리 색은 고정이고, 패딩·가운 아래 다리 색도 고정입니다.
- 모자를 쓰면 똥머리를 숨깁니다. 일부 짧은 머리는 모자 아래로 옆머리가 조금 보입니다.
- 정면에 가까운 3/4 시점 하나만 있습니다. 왼쪽을 볼 때는 거울 반전이라 광원도 반전됩니다.
- 여러 캐릭터가 동시에 마운트되면 애니메이션 위상이 같아질 수 있습니다.
