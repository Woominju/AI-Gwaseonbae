# CAMPUS_WORLD_3_0 — 선배 광장·서울캠퍼스·글로벌캠퍼스 공간 설계

정의: `web/src/lib/world/world.ts`, 일러스트: `web/src/components/world/art/` (아트 규칙 ART_DIRECTION_3_0.md)

## 1. 구조 변경
2.0에서는 광장·도서관·카페가 최상위 공간이었습니다. 3.0에서는 **월드 3개 → 하위 장소** 구조로 바꿨고, 2.0 장소는 하위 장소로 재사용했습니다.

| 월드 | 장소 (장면 ID, 폭) | 성격 | AI 선배 |
|---|---|---|---|
| **선배 광장** (공통 허브) | 선배 광장 `hub` (1600) | plaza | 3명 (정자 앞) |
| **서울캠퍼스** | 캠퍼스 야외 `seoul_yard` (1600) | plaza | 하루 |
| | 도서관 `seoul_library` (1000) | library | 저울 |
| | 선배 카페 `seoul_cafe` (1000) | cafe | 도담 |
| | 진로 상담실 `seoul_counsel` (1000) | counsel | 3명 |
| **글로벌캠퍼스** | 호숫가 `global_lake` (1600) | plaza | 하루 |
| | 숲속 도서관 `global_library` (1000) | library | 저울 |
| | 휴게 라운지 `global_lounge` (1000) | cafe | 도담 |
| | 진로 상담실 `global_counsel` (1000) | counsel | 3명 |

- 2.0 주소 호환: `/campus?place=plaza|library|cafe`는 각각 `hub`, `seoul_library`, `seoul_cafe`로 이어집니다.
- 장소 성격(theme)은 AI 선배의 인사 훅과 환경음 종류를 정합니다. 상담 엔진에는 전달하지 않습니다.
- 모든 장소에서 모든 선배 경험(가상 19건)을 탐색할 수 있습니다. 캠퍼스별로 데이터를 나누지 않습니다.

## 2. 장소별 설계
### 선배 광장 (허브)
- 시설:
  - 중앙 분수대
  - 화단 정원
  - 벤치(가벼운 대화 시작)
  - 캠퍼스 이동 표지판(왼쪽 서울, 오른쪽 글로벌)
  - AI 선배 상담 정자(3명 상주)
  - 선배 경험 게시판(→ `/alumni`)
  - 옷장 부스(→ `/wardrobe`)
  - 진로 정보 안내소(→ `/market`)
- 상담 없이 산책만 해도 됩니다. 폭이 1600이라 카메라가 학생을 따라갑니다.

### 서울캠퍼스 — 도심형
- 야외: 붉은 벽돌 학술 건물, 시계탑, 은행나무 길, 도시 스카이라인, 출입문 3개(도서관·카페·상담실)
- 도서관: 월넛 목재, 아치 창 빛줄기, 책장, 긴 열람 책상, 스탠드(켜기·끄기)
- 선배 카페: 에스프레소 머신, 분필 메뉴판(→ Career Market), 노트북(→ Skill Gap)
- 진로 상담실: 네이비 패널 벽, 화이트보드(→ 진로 비교), 로드맵 코르크보드(→ 로드맵), 진로 지도 액자(→ 그래프), 빨간 질문함(→ 선배 네트워크)

### 글로벌캠퍼스 — 자연형 (명수당 분위기 참고)
- 호숫가: 넓은 호수, 물 위 전통 정자(일반적 정자 양식으로 새로 디자인)와 다리, 버드나무, 숲 언덕, 연잎, 오리 가족, 숲길, 자작나무·유리 건물
- 숲속 도서관: 자작나무와 유리, 숲이 보이는 통창, 지구본(→ 그래프)
- 휴게 라운지: 소파(가벼운 대화), 자판기, 노트북(→ Skill Gap), 보드게임
- 진로 상담실: 세이지색 벽, 펠트 보드, 숲 창, 새집 모양 질문함
- 서울과 **건축 양식·재료·색·환경이 모두 다릅니다**. 배경색만 바꾼 복제가 아닙니다.

## 3. 인터랙션 (2.0 기능 유지)
| 기능 | 3.0 |
|---|---|
| 이동 | 바닥 클릭·터치, 방향키/WASD, 2.5D 원근(0.82~1.08배), 걷기 애니메이션 |
| 카메라 | 폭 1600 장면은 학생을 따라감. 모바일은 480×600 뷰(4:5 프레임)로 확대해 따라감 |
| 장소 이동 | 상단 월드 탭·장소 탭, 출입문/표지판 오브젝트(주황 → 표시), 0.28초 페이드 |
| 오브젝트 | ! = 정보·기능 연결, → = 장소 이동. 팝업에서 해당 기능으로 이동 |
| 상담 | 선배 클릭 → 다가가 인사 → 오른쪽(모바일은 대화 탭) 패널 |
| 학생 캐릭터 | `/wardrobe`에서 저장한 외형. 모든 월드에 같은 외형을 쓰고 새로고침해도 유지 |
| AI 선배 꾸미기 | 성격·인사 방식·헤어·상의·색·모자·안경·액세서리 (학생 외형과 별도 저장) |
| 소리 | 2.0 Web Audio 합성 유지(기본 꺼짐). 물소리 효과 추가. 상담실은 실내 환경음 |
| 접근성 | 움직임 줄이기(`.w3-reduce`), 키보드 조작, aria 레이블, 대시보드 상시 이동 버튼 |
| 대시보드 복귀 | 진로 화면 오른쪽 아래 "선배마을로 돌아가기" → 마지막 장소로 복귀, 대화 복원 |

## 4. 한계
- 장애물 충돌 판정 없이 걷기 영역(사각형)만 있습니다. 낮은 소품 일부(러그·다리 끝)는 걷기 영역과 겹칩니다.
- 출입문 일부(서울 야외의 카페 문 x=1000)는 처음 화면 오른쪽 끝에 있어, 걸어가거나 장소 탭을 써야 합니다.
- 장면은 무거운 SVG 필터(그림자)를 많이 씁니다. 저사양 기기에서는 배경을 PNG로 미리 렌더링하는 최적화를 검토해야 합니다.
- 다른 사용자가 같은 공간에 보이는 실시간 멀티플레이는 구현하지 않았습니다(1인 공간).
