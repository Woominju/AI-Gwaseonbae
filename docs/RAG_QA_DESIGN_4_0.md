# RAG_QA_DESIGN_4_0 — 근거 기반 RAG, 진로 비교, 확장 설계

## 1. 데이터 현황 (구분 유지)
| 데이터 | 건수 | 성격 |
|---|---|---|
| 선배 기록 S-01~S-19 | 19 | 전부 가상 (`is_synthetic: true`) |
| 시연 Q&A Q-01~Q-10 | 10 | 전부 가상. 가상 선배 기록에서 파생 |
| 검증된 실제 동문 경험 | **0** | 실제 데이터 없음 |
| 공식 학사·채용 자료 | **0** | 등록 안 됨, 추정 답변 금지 |
| NCS·채용공고 | Fixture | 실시간 정보 아님 |

## 2. Q&A 모델 (`web/src/lib/qa/schema.ts`)
필수 항목: `question_id, question_text, answer_text, source_type, source_reference, verified_status, is_synthetic, consent_status, visibility, department, career_category, created_at, updated_at`
추가 항목: `pii_checked, reviewed_by, review_note`

## 3. 등록과 검증
```
관리자 등록(POST /api/admin/qa) → pending (검색 제외)
  → 승인(POST /api/admin/qa/:id, pii_checked 필수, 자동 개인정보 점검)
  → verified (검색 대상)
  → 철회 시 withdrawn (캐시 포함 즉시 제외)
```
실제 데이터가 검색되려면 **승인 + 동의 + 개인정보 확인 + 출처 참조**가 모두 필요하다. 공개 시연 모드는 저장소를 읽지 않고 가상 데이터만 쓴다. 저장 위치 `web/data/qa/store.json`은 Git에서 제외되고 권한 600이다.

자동 점검은 전화번호·이메일·주민등록번호·학번 형식만 찾는다. 이름 등은 관리자가 확인해야 한다.

## 4. 검색과 생성
- 기존 임베딩·리랭커·로컬 n-gram 경로를 재사용한다(`retrieval/service.ts`의 `textScores`).
- 관련도 0.42 이상, 최대 3건. 프롬프트와 화면에 출처 유형을 표시한다.
- 3.0은 프롬프트가 모든 근거를 "가상"으로 고정 표기했다. 4.0에서 실제/가상을 구분하도록 수정했다.
- 선배 경험, 직무 정보, 채용 시장 정보, AI 분석은 화면에서 구분해 표시한다. 선배 답변은 "자기 보고"이며 채용 조건이 아니다.
- 없는 ID의 인용은 제거한다.

## 5. 한계
- 관리자 Q&A는 API만 있고 화면은 없다.
- 실제 선배 답변을 Q&A로 자동 수집하는 흐름은 없다(관리자가 `alumni_answer`로 등록).
- 임계값은 시연 데이터로 정한 값이며 실제 데이터로 재보정해야 한다.
- 검증은 로컬 검색 경로로 수행했다. 임베딩·리랭커 경로의 Q&A 검색은 사이드카를 띄워 시험하지 않았다.
- JSON 파일 저장소이며 단일 프로세스 전제다. 운영 시 DB가 필요하다.

## 6. 다중 관점 진로 비교 (Phase D)
진로 비교 질문에 "선택지 비교 정리"를 제공한다. 현실적인 조건, 장기 준비, 대안, 가치 확인, 다음 행동, 불확실성으로 구성된다. 비교 엔진의 계산값으로 만든 규칙 기반 출력이고, 스타일과 무관하며 LLM을 호출하지 않는다. 학점이 언급되면 그것만으로 판단할 수 없다고 명시한다.

**Tree of Thoughts는 구현하지 않았다.** 복수 후보 생성, 평가, 선택, 탐색 경로 수정이 없다. 후속 연구로 하려면 (1) 후보별 평가 기준, (2) 호출 수 증가 대비 품질 이득의 측정, (3) 사용자에게 최종 선택지·근거·불확실성·실행 계획만 노출하는 구조가 필요하다.

## 7. 학교생활 상담 확장 (Phase E, 설계만)
| 영역 | 필요한 것 | 현재 |
|---|---|---|
| 수강신청·졸업요건·학점 관리·교환학생 | 학년도·소속·캠퍼스별 공식 문서, `official_doc` 등록 | 공식 자료 0건, 규칙 기반 안내만 |
| 동아리·교내 활동 | 운영 주체가 확인한 목록 | 없음 |
| 인간관계 | 상담 범위 정의, 위기 분리 | 일반 공감 응답까지만 |
| 학생상담센터 안내 | 학교가 확인한 공식 연락처 | 부서명만 안내, 번호 없음 |

학사 규정은 공식 출처가 있는 내용만 사실로 제공한다. `official_doc`은 출처 URL과 적용 학년도를 `source_reference`에 기록하는 구조로 확장한다.

## 8. 위기 대응 분리
위기 신호는 스타일 처리와 LLM 앞에서 분기해 고정 문구만 보여 준다(단위 테스트). 안내 번호는 2026-11-09 정부 자료로 확인했다: 109(자살예방상담전화, 24시간), 1577-0199(정신건강 위기상담, 24시간), 1388(청소년상담, 만 9~24세, 24시간), 112·119. 정규식 탐지는 간접 표현을 놓칠 수 있고, 운영 전 전문가 검토와 학교 상담센터 연락처 확인이 필요하다.
